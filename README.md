# CET6 复习室

词汇训练、20 词摸底和整卷计时练习。作答保存在设备本地。

- **Android**：在 Releases 下载 APK。打包和迁移说明见 [Android README](android/README.md)。
- **网页**：见下文的本地预览说明。

本项目原创源码采用 MIT 许可证。PDF.js 保留其 Apache-2.0 许可证。第三方试卷、原声及解析由原站提供。

## 网页版

Buildless HTML/JS，浏览器本地保存，无用户答卷上传。

本地预览：`python -m http.server 8766 --bind 127.0.0.1`，打开 `/dist/`。

检查：`node --check dist/app.js`、`node check-flow.cjs`。

资料直接由来源网站加载：2025年6月六级第一套，CET通试卷、原声、20页解析；答案与南京大学同套自测交叉核对。PDF.js 4.10.38，Apache-2.0。网络用于加载来源文件；试听后再开始。音频实际容器为M4A，已纠正Blob MIME。

考试按30/30/40/30分钟分部计时。原卷第9页答案排除；共用页面按部分裁切。解析在提交后显示，属于界面隐藏，不提供防作弊安全保证。本工具用于个人诊断，不换算710分。

作答、标注与计时保存于当前浏览器 localStorage，键 cet6-baseline-202506-1-v1。交卷后导出 JSON 交回聊天，作文翻译人工批改。更换设备或清除浏览器数据不会同步答卷。刷新会记录中断，当前部分倒计时继续。

## 词汇训练室（三轮版）

首页 study.html；整卷 /?exam=1；基础摸底 vocabulary.html。当前去重后383词及短语，涵盖基础20词和整套卷面候选词（听力选项、阅读、写作与翻译）。教学例句均原创，翻译和搭配保留；来源词形保存在各题库的 evidenceForm，重复项合并别义及来源。

固定三轮：英文选中文 → 中文选英文 → 看英文填写中文意思。每词三轮全部通过才记当日通过，任一轮答错重置第1轮；次日新加坡时间零点重新进入复测。词库选项按释义交集排除直接同义的干扰词。中文填空接受常见同义表达，无法判断时待核对，允许纠正判分并本地记住同义表达，日志记录manual。

自动混排词汇并分组。没有每日训练上限，没有单词重试上限；本组结束可继续下一组；卡住可暂存稍后。当天通过词自动从新组排除，次日再测。跨日未完成组重回第一轮，保留原日志。刷新可继续当前组，中文输入法组合键期间Enter不提交。

学习记录继续使用 cet6-learning-v2 存储键，内部version升级3。保留旧版作答日志、错词与评分纠正，旧模式未完成队列不冒充三轮通过，按新规则重新验证。兼容v2/v3 JSON备份，本地文件导入不上传服务器。20词自由释义摸底评分保留。

检查：node check-three-rounds.mjs 验证383词数据、选项、三轮门槛、错误重置、次日自然日复测、迁移、备份与不限量选词；node check-learning.mjs 保留旧词汇核心行为回归；node check-flow.cjs 验证整卷流程。


## 间隔复习与通过词抽查

新词先完成三轮；通过后次日安排一次中文回忆复测。到期复测正确后，下次间隔依次2、4、7、15、30个自然日；每次从本次作答日期计算，新加坡时区。同日重复或提前随机抽查正确不提高间隔，也不推迟原计划。

自动抽查已通过词，覆盖历史三轮通过且目前不需要重学的词。抽查答错会清除当前通过状态，设置needsRelearn，间隔回到起点；立即从完整三轮开始。重学三轮通过后次日再测。过期优先，已通过且未到期词不占普通新词组，可以随时随机抽查。

复习间隔为参考遗忘规律制定的可调整工程规则，不是艾宾浩斯实验直接给出的最优日期，也不绘制虚构的个人记忆保留率。参考：Murre & Dros (2015), https://pubmed.ncbi.nlm.nih.gov/26148023/ ；Cepeda et al. (2008), https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf 。

新增检查：node check-spaced-reviews.mjs，覆盖抽查池、到期递进、提前抽查不推迟、同日不升级、失败重学及备份。


## 易混干扰项与双语反馈

383个目标词均配置近义词或近义表达，有可靠对比时另配易混词和辨析。word-relations-a/b按目标词索引分区；word-contrasts.mjs补充likely/like、resource/source、wealthy/healthy等重点对比，优先易混词，其余用词形相近项补足。目标的已接受释义、显式近义词和重复英文选项排除；affect等需要词性区分时在题干补充提示。近义表达在反馈中教学，不直接作为错误选项。

第1轮作答前只显示中文选项，第2轮只显示英文选项；作答后所有选项显示英文＋中文，禁用状态也保持可读。下方继续展示原有例句、翻译、搭配，并展示近义表达与易混词辨析。未作答的旧题会升级干扰选项，已作答题保留原选项与记录并补双语。

验证：node check-word-contrasts.mjs，检查383词覆盖、选项双语元数据、易混优先、唯一答案键和与可接受释义不重叠，以及用户点名的三组对比。网页已检查英选中和中选英作答前后语言变化。


## 单入口混合训练、用时与拼写辅助

首页只保留“开始/继续词汇训练”，不再显示训练范围和组数选择。内部自动分组：到期与错词优先，有复习积压时穿插最多3个新词，并酌情加入1个历史通过词抽查；新词按教学核心优先级排列，当前383词并非完整六级统计高频词库。专业太空术语降低教学优先级。旧未完成组保留当前题及各词进度，后续队列改为自动混排。

每题保存展示时间、首次提交时间、有效活跃用时、总历时、页面中断、读音与提示使用情况；切换页签、离开训练视图及关闭页面会暂停计时。中文输入草稿随输入保存。用时不影响对错；无提示、未中断的中文回忆慢而正确时，在到期复习中可适当缩短下一间隔。提前随机抽查仍不推迟原计划。该规则用于辅助调度，不宣称拟合个体记忆曲线。

同一词在一次学习周期累计错2次，触发辅助轮：中文提示＋可点击读音＋英文拼写，可先查看正确拼写。辅助正确只清除当前困难计数并回到第1轮，不直接算三轮通过；辅助错误可继续练或暂存。辅助结果与提示使用单独记录。浏览器不支持读音时提供文字提示。

新增检查：node check-adaptive-training.mjs，覆盖混排、新词教学优先、抽查、有效用时保护、提示/中断保护、拼写辅助及不冒充通过。
